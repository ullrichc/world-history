# Before Bronze: notes for Claude

A narrated, interactive world history of the Stone Age (first hominins to the arrival of metal), built as a static web
app with no build step. `README.md` describes the features; `content/SCHEMA.md` describes the content format.
The current work item is a watchable documentary series inside the app: read `docs/series-plan.md` before starting.

## The user’s standing preferences

Apply these to chat replies and to every piece of text in the app (captions, articles, cards, narration scripts):

* No emojis. No horizontal dividers such as `---` in prose. No em dashes as punctuation. No capital letters for emphasis.
* Correct diacritics always (Çatalhöyük, Göbekli Tepe, Dolní Věstonice, Ertebølle, Předmostí); never ASCII stand-ins.
* Typographic quotation marks for the language (“…” and ‘…’ in English); straight quotes only in code.
* Thorough, detailed, based on the latest research, naming researchers and years.
* Where views differ, explain every view fairly and neutrally, including non-orthodox ones, and state the state of
  the debate as facts (who argues what, what evidence, what the response was). The viewer draws the conclusion.
  No loaded words (fringe, pseudo, debunked, crank) in the app’s own voice; no false balance on facts either.
* Do not open pull requests unless the user asks. Commit with clear messages and push to the working branch.

## Layout

```
index.html        page shell; loads vendor, data, then js/ as classic scripts on a global window.BB
css/app.css       all styles; dark, single theme (tokens on :root, color-scheme: dark)
js/util.js        BB helpers: time formatting, seaLevel/iceFactor, REGIONS, CATEGORIES, store (safe localStorage)
js/globe.js       Globe class (D3 orthographic canvas + flat Equal Earth): flyTo, fitBox, setTime, setSites, setRoutes
js/timeline.js    log-scale timeline 7.5 Ma to 2 ka, stages, sea-level curve, chapter markers, scrubbing
js/narrator.js    Narrator: engines recorded (audio + sentence timings), browser speech, captions only
js/app.js         boot, modes (journey, explore), overlays (read, tree, about), transport, cinema, intro, deep links
js/watch.js       Watch mode: episode list, scene player (several voices, cue timings), cards, captions, scrubber
js/reader.js, tree.js, about.js, emblems.js, hand.js
data/content.js   generated from content/ (window.LD_CONTENT)
data/series.js    generated by tools/build-series.mjs from content/series/ (window.LD_SERIES)
data/series-audio.js  generated by tools/narrate-series.py: per scene file, duration, cue and sentence timings
audio/series/     one MP3 per episode scene, plus voices/ audition clips
content/series/   series.json (speakers, voices), NN-id.json per episode, SCHEMA.md
tools/            build-series.mjs, narrate-series.py, style-rules.mjs (shared prose checks)
data/narration.js generated by tools/narrate.py (window.LD_NARRATION: per chapter file, duration, sentence [start,end])
data/geo.js, data/climate.js   generated map layers and LR04 / sea-level curves
audio/            one MP3 per chapter
content/          source text: chapters/NN-id.json, species.json, glossary.json, methods.json, SCHEMA.md
tools/            validate-content.mjs, build-content.mjs, build-geo.mjs, build-vendor.mjs, narrate.py, lexicon.json
```

Time is always “years ago counted from 2000 CE” (9600 BCE is 11600). Coordinates are decimal degrees.

## Commands

```sh
npm run build:content                 # validate every content file, then write data/content.js
python3 -m http.server 8123           # serve the repo root for testing (any static server works)
python tools/narrate.py [ids]         # render narration (only changed chapters); --check prints phonemes
node tools/build-series.mjs           # validate and compile the series; then:
python tools/narrate-series.py [episode-id]   # render changed scenes; --audition renders voice clips; --check phonemes
```

The series renders at about 3.5 times real time; a 45-minute episode takes about 13 minutes. Scenes whose text,
voices or lexicon are unchanged are skipped (hash in data/series-audio.js).

## Narration pipeline (Kokoro)

* Setup: `python3 -m venv .venv && . .venv/bin/activate && pip install kokoro-onnx soundfile lameenc`, then download
  `kokoro-v1.0.onnx` and `voices-v1.0.bin` from
  `https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/` into `tools/raw/` (gitignored).
* Voice `af_heart`, speed 0.96, 24 kHz, MP3 via lameenc. Measured pace: about 149 words per minute including pauses
  (10,384 words gave 69.6 minutes). Rendering runs at about 3.5 times real time on 4 CPUs; do not run browser tests
  at the same time, they halve the speed.
* Available English voices: af_alloy af_aoede af_bella af_heart af_jessica af_kore af_nicole af_nova af_river
  af_sarah af_sky am_adam am_echo am_eric am_fenrir am_liam am_michael am_onyx am_puck am_santa bf_alice bf_emma
  bf_isabella bf_lily bm_daniel bm_fable bm_george bm_lewis (a = American, b = British; f/m).
* Hard names are spoken from IPA in `tools/lexicon.json` (espeak en-us symbol set, validated against the model
  vocabulary). Hyphenated respellings make Kokoro stress every syllable, so never use them for the neural voice;
  chapter `pronounce` respellings exist only for the browser’s speech engine.
* Phonemizer pitfalls already handled in `narrate.py` (keep them when refactoring): decimals such as 1.8 are split at
  the point unless spelled out; four-digit years must be converted to spoken form (1836, 2300 BCE, 1800s);
  text passed to the phonemizer must not start with punctuation; Roman numerals are read as “roman two”, so give
  them lexicon entries (“Ohalo II”).

## Testing

* Playwright is preinstalled; launch Chromium with `executablePath: '/opt/pw-browsers/chromium'` (never run
  `playwright install`). Add `--autoplay-policy=no-user-gesture-required` to test audio.
* Check desktop (1440×900) and phone (390 wide, `devices['iPhone 13']`): no horizontal scroll, top bar and dock fit.
* Python’s http.server has no range requests; the narrator fetches audio into blob URLs so seeking works anyway,
  and falls back to the plain file if a host refuses blob media.

## Preview artifact

A private preview is published at https://claude.ai/artifact/JU3gfh2ovBatUJnn26T6J7. To update it from a new
conversation, read it first (Artifact `read` with that URL), then publish with `url` set to it.
The published page is `index.html` without the document skeleton (no doctype, html, head or body tags), with
`css/fonts.css` replaced by a Google Fonts link (Fraunces with opsz, wght, SOFT, WONK; Literata 400/600 with italics;
IBM Plex Mono 400/500), D3 from `https://cdnjs.cloudflare.com/ajax/libs/d3/7.9.0/d3.min.js` and TopoJSON client from
`https://cdn.jsdelivr.net/npm/topojson-client@3.1.0/dist/topojson-client.min.js`. Everything else (css/app.css,
js/*, data/*, audio/*) is published alongside through `files`. Limits: 64 MB and 255 files per publish, 256 MB per
version (spread larger sets over several publishes to the same url), 15 MB per binary file.
